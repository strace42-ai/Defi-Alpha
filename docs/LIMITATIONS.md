# Журнал технических ограничений

Актуально на 2026-11-05 (v0.2.0). Ограничения также показываются в интерфейсе («Источники данных»).

| # | Ограничение | Влияние | Что сделано |
|---|---|---|---|
| 1 | GeckoTerminal бесплатно ≈ 10 запросов/мин; new_pools — 20 пулов/стр., ≤ 10 стр. | Первое сканирование 5 сетей ≈ 5–10 мин; при частом появлении пулов возможны разрывы | Равномерный лимитер 9/мин, адаптивная пагинация до прошлого самого нового пула, журнал разрывов |
| 2 | Solana: ~20 новых пулов за 40 с | Полный поток недостижим бесплатно | Сеть экспериментальная и выключена по умолчанию; покрытие показывается честно |
| 3 | new_pools покрывает только последние часы, исторического «списка всех токенов за 90 дней» нет | 90-дневный скрининг неполон | Добор: топ-пулы по объёму (младше 90 дн.), недавние протоколы DefiLlama, накопление собственной базы. Неактивные пулы прошлых дней не находятся |
| 4 | Списки пулов токена (GT 1 стр. + DS) могут быть неполными | Самый ранний пул может быть не найден → возраст занижен | Возраст помечается предварительным без TGE; сверка с первым ончейн-mint |
| 5 | Публичные RPC без архива | Нет исторического totalSupply | История из событий Transfer + сверка с текущим totalSupply |
| 6 | eth_getLogs: официальный RPC Robinhood до 10 млн блоков, частые запросы → 429; публичные RPC других сетей — 1–10 тыс. блоков | Полная история mint для старых токенов на ETH/Base медленная | Сканирование порциями с сохранением позиции и бюджетом вызовов на запуск |
| 7 | Нестандартные токены (rebase, reflection, mint без Transfer) | Восстановленная история не совпадёт с totalSupply | Явный статус «не сходится», пункт скоринга не засчитывается, блокирующий риск |
| 8 | Blockscout Robinhood закрыт Cloudflare-проверкой из облачной сети (с домашнего IP может работать) | Нет верификации исходного кода | Верификация = UNKNOWN; обход защиты не выполняется |
| 9 | Селекторы функций в байткоде — эвристика | Ложные срабатывания/пропуски; функции в прокси — в реализации | Для прокси анализируется реализация; формулировки — «индикатор», а не заключение |
| 10 | Нет машиночитаемого источника No-VC | Автоматический PASS невозможен | Только ручная запись с доказательством; DefiLlama raises → FAIL |
| 11 | DefiLlama: нет адаптера комиссий у части протоколов (напр. Longbow — HTTP 400) | Комиссии/выручка «н/д» | Отображается как «нет данных», не 0; пункты скоринга «не проверено» |
| 12 | Метки адресов (gauge/escrow/team) берутся только из документации и ручного ввода | Сравнение «mint в контракты эмиссии vs бюджет» неполно без меток | Показываются и «все mint», и «mint в помеченные контракты» |
| 13 | Даты недельных бюджетов FABLES выведены из времени запуска | Возможен сдвиг на часы/дни | Помечено как предположение в версии токеномики |
| 14 | Держатели (GT) — топ-10 с контрактами локов и пулов | Концентрация завышена | Пункт скоринга с оговоркой; полноценный анализ холдеров не реализован |
| 15 | Перевод мульти-чейн токенов | FDV(totalSupply) на одной сети ≠ глобальная | Оговорка в фильтре MCAP |
| 16 | Время — UTC в базе; интерфейс показывает локальную зону браузера | — | Зона подписана в подвале, UTC — во всплывающей подсказке |
| 17 | GeckoTerminal market_cap_usd может совпадать с FDV | Ложный «circulating» | Совпадение ±0.5% помечается not_evidence |
| 18 | Время большинства mint-событий интерполировано (точное время — только у опорных блоков) | Даты на дневных графиках приблизительны | Поле `ts_source`; недельные сравнения — по точным границам-блокам |
| 19 | Публичный RPC хранит состояние только для недавних блоков | `totalSupply()` на блоке логов доступен лишь сразу после сканирования | Если чтение на блоке не удалось — читается latest, метод фиксируется, совпадение засчитывается только точное |
| 20 | Зафиксированные версии требуют Python 3.11+ | На Python 3.10 установка не пройдёт | Проверка версии в `start.bat` и диагностике |
| 21 | Запуск на Windows не проверялся | Возможны проблемы окружения у пользователя | `diagnose.bat`; сообщения об ошибках в `start.bat` |
