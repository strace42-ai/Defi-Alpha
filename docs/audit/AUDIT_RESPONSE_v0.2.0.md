Дата: 2026-11-05. Новых функций не добавлялось. Каждое исправление закреплено тестом в `tests/test_audit_regressions.py`,
который **падал на v0.1.0** (`regressions_before_fix.txt`: 10 из 15 тестов падали) и проходит на v0.2.0

Как воспроизвести: `pip install -r requirements-dev.txt` → `python -m pytest -v tests/test_audit_regressions.py`.
