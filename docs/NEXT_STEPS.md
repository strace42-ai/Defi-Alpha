## Что сделано в сессии 1
- Этап 0 (проверка API) — `docs/STAGE0_API_FEASIBILITY.md`.
- Этапы 1–5 в рабочем виде: обнаружение, 6 фильтров, уровни A–E, фундаментал DefiLlama, ончейн-эмиссия EVM,

## Приоритеты следующих шагов
1. Проверить запуск на Windows; при проблемах — поправить `start.bat` по сообщениям.
2. Анализ держателей (топ-20/50) через `eth_getLogs` Transfer с агрегацией балансов для токенов уровня C+ на Robinhood
   (RPC позволяет большие диапазоны), с метками адресов.
3. Метки адресов gauge/voter для FABLES (из документации/контрактов Voter) → точное сравнение «эмиссия vs бюджет».
4. Верификация кода: опционально Etherscan V2 (бесплатный ключ) для поддерживаемых сетей; Blockscout — проверить с
   домашнего IP пользователя (из облака закрыт Cloudflare).
5. Отслеживание переводов крупных получателей эмиссии в пулы (адреса пулов уже есть в таблице `pools`).
6. Telegram-уведомления (после стабилизации).
7. Solana: поиск mint-событий через индексатор (бесплатных вариантов с историей мало) — оценить.
